# LinguoBook

Intelligent book reader with word translate feature.

LinguoBook was built with a simple goal: to make learning new words easy and intuitive by reading e-books.

Designed with a clean and user-friendly interface, it includes all the essential functions you need:

- Book Import: Supports all popular ebook formats.

- Bookshelf: Easily add books to your collection and track your reading progress.

- Translation: Instant translations between English, Polish, Ukrainian, Czech, German, Spanish, French, Italian with speech-to-text function. More languages are on the way!

- Personal Dictionary: Add newly discovered words directly to your built-in dictionary for later review.

- Localization: The app currently supports English, Polish, Ukrainian, and Czech interfaces.

## ✨ Key Features

- 🌍 **Instant Translation:** Integrated Google, PONS, and Linguee translators.
- 🔊 **TTS Support:** Listen to native pronunciation for every word.
- 📖 **E-book Formats:** Support for FB2, EPUB, MOBI, TXT.
- 🎨 **Material Design 3:** Customizable UI with dynamic themes.
